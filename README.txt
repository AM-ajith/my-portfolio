AJITH DESIGN — DEMO PORTFOLIO

Files:
- index.html
- css/style.css
- js/main.js
- images/ (place your own images here)

Run it:
1. Extract Ajith-Design-Demo.zip.
2. Open index.html in your browser, or open the folder in VS Code and use the Live Server extension.
3. GSAP and Google Fonts are loaded from CDNs, so those features need an internet connection.

Customize before publishing:
- Replace demo project concepts with your real work.
- Update hello@ajithdesign.com to your actual email.
- Update your bio and services to match what you offer.
- Add real project images to images/ and update the HTML/CSS accordingly.

This is a static front-end demo. The contact link opens the visitor's email app; it does not store form submissions.
